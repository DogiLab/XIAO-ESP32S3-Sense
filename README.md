# XIAO ESP32S3 Sense

Tested examples for the **Seeed Studio XIAO ESP32S3 Sense**.

This repository contains simple, hardware-validated sketches focused specifically on this board.

## Goal

Provide clear working examples for functions that can otherwise be difficult to find or configure specifically for the XIAO ESP32S3 Sense.

## Examples

* Camera web streaming 
* Camera tests
* PDM microphone
* Audio / I2S
* Wi-Fi
* Storage

## Validation

Examples are added only after being tested on physical XIAO ESP32S3 Sense hardware.
